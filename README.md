# ✅ Sharifi Todo List

A simple and modern Todo List application built with **React.js**.

This project is a functional task management application that allows users to add, complete, undo, delete, and filter their daily tasks with a clean and minimal user interface.

---

## 📌 About The Project

**Sharifi Todo List** is a frontend project developed using React.  
The main goal of this project is to practice React fundamentals such as state management, event handling, conditional rendering, and working with arrays.

Users can easily manage their tasks and track completed activities through a simple and interactive interface.

---

## ✨ Features

- ➕ Add new todo tasks
- ✅ Mark tasks as completed
- ↩️ Undo completed tasks
- 🗑️ Delete tasks
- 🔎 Filter tasks by status:
  - All Tasks
  - Completed Tasks
  - Uncompleted Tasks
- 📊 Display total number of tasks
- 📈 Display completed task count
- ⚡ Fast and responsive interface
